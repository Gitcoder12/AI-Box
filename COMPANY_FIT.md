# AI-Box — Company and Team Fit

Company matches are prospective skills fit, not evidence of adoption or endorsement.

## Project thesis

A single browser page where you can send the same prompt to several AI providers and compare their answers side by side.

## OpenAI

**Relevant public technical areas:** Model evaluation, product engineering and provider integration.

**Potential roles:** Full-stack Engineer, AI Product Engineer, ML Engineer, Developer Tools Engineer or Evaluation Engineer.

**Evidence to build:** Static frontend with provider panels for Claude, Gemini and DeepSeek, user-supplied API keys, shared prompt/system instruction, parallel responses and browser-local workspace state. Because it is client-side and BYOK, keys can be exposed to browser extensions, developer tools or local storage if handled poorly; inspect storage and network paths before public use.
